# APU-Installation-HomeAssistant-Freedombox
Manual for the Installation of Home-Assistant or Freedombox on PCEngines APU3 board. Two methods are described: Using Alpine Linux with Docker or updating the BIOS to UEFI and using published images. 
## Downloads

- **APU3 UEFI firmware ROM:** [`firmware/pcengines_apu3_v0.9.rom`](firmware/pcengines_apu3_v0.9.rom) (also available in [GitHub Release v0.9.1](https://github.com/huubsch/APU-Installation-HomeAssistant-Freedombox/releases/tag/v0.9.1))  
- **Large system images (DTS, ISO, WIC):** available only via [GitHub Release v0.9.1](https://github.com/huubsch/APU-Installation-HomeAssistant-Freedombox/releases/tag/v0.9.1)  

**Verify downloads** using the included SHA256 checksums.
